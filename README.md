I work on single-cell data analysis and build R tools for studying fibroblast states and preparing research figures.

My research interests include wound repair, pathological scarring, and the cell programs that shape tissue remodeling.

### Selected projects

| Project | What it does | Start here |
| :--- | :--- | :--- |
| **[FibroDynMix](https://github.com/jiangcongxin/FibroDynMix)** | Models fibroblast-state mixtures from single-cell counts using marker-anchored negative-binomial models. | [Function index](https://github.com/jiangcongxin/FibroDynMix/blob/main/docs/package-function-index.md) · [Releases](https://github.com/jiangcongxin/FibroDynMix/releases) |
| **[ncfigR](https://github.com/jiangcongxin/ncfigR)** | Turns tidy analysis tables into consistent bioinformatics figure panels, with shared styling and PDF, SVG, and PNG export. | [Install and example](https://github.com/jiangcongxin/ncfigR#installation) |
| **[NC Bioinformatics Figure Skills](https://github.com/jiangcongxin/nc-bioinformatics-figure-skills)** | Collects figure recipes, source-data conventions, and seven R plotting toolkits for single-cell, spatial, and multi-omics work. | [Package map](https://github.com/jiangcongxin/nc-bioinformatics-figure-skills#r-package-map) |
